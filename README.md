# txtforepub

一个基于 Vue 3 的前端小工具：把 `.txt` 小说文本在浏览器本地转换为可用的 `.epub` 电子书文件。

不需要后端服务，不上传文本到服务器，转换与下载都在本地完成。

## 项目介绍

`txtforepub` 的目标是提供一个简单、可直接使用的 TXT -> EPUB 转换页面，适合个人整理电子书、快速预览章节结构、生成可导入阅读器的文件。

### 适用场景

- 手里只有 `.txt`，想快速转成 EPUB
- 需要给电子书补充基本元数据（书名、作者、语言）
- 想先看分章结果，再下载 EPUB

## 功能特性

- 支持上传 `.txt` 文件
- 支持粘贴文本并手动编辑
- 支持设置书名、作者、语言
- 支持三种分章策略
- 生成标准 EPUB 结构并自动下载
- 显示章节预览（最多前 10 章）

## 技术栈

- `Vue 3`
- `Vite`
- `JSZip`
- `file-saver`

## 快速开始

```bash
npm install
npm run dev
```

启动后打开终端显示的地址（默认 `http://localhost:5173`）。

## 构建与预览

```bash
npm run build
npm run preview
```

## 使用说明

1. 填写书名、作者、语言。
2. 上传 `.txt` 文件，或把内容粘贴到文本框。
3. 选择分章方式。
4. 点击“生成 EPUB 并下载”。
5. 使用阅读器打开生成的 `.epub` 文件。

## 分章模式说明

- `自动`：优先识别“第X章 / Chapter 1”样式标题，识别失败时按字数切分。
- `只按章节标题`：仅按章节标题识别，适合排版规范的小说文本。
- `按字数切分`：按设定的每章最大字数切分，适合无章节标题文本。

## 当前限制

- 当前版本只处理纯文本，不保留复杂排版。
- 目录为单层章节结构。
- 若原文章节标题不规范，建议使用“按字数切分”。
