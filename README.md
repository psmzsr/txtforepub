# txtforepub

一个基于 Vue 3 的本地小工具，用来把 `.txt` 小说文本转换成 `.epub` 电子书。

特点：

- 纯前端运行，不依赖后端
- 支持 TXT 上传和正文编辑
- 支持自动分章 / 按章节标题 / 按字数切分
- 支持添加封面
- 支持在正文中插入图片
- 支持生成并下载标准 EPUB 文件

## 安装与启动

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 基本使用

1. 填写书名、作者、语言。
2. 上传 TXT 文件，或直接把正文粘贴到文本框。
3. 选择分章方式。
4. 可选：上传封面。
5. 可选：上传正文插图，并把插图标记插入到正文。
6. 点击“生成 EPUB 并下载”。

## 分章规则

- `自动`：优先识别 `第X章` / `Chapter 1` 这类标题。
- `只按章节标题`：只按标题切分，适合排版规范的小说。
- `按字数切分`：按每章最大字数切分，适合无标题文本。

## 封面功能

- 上传封面后，会写入 EPUB 元数据和单独的封面页。
- 支持常见图片格式：`JPG`、`PNG`、`GIF`、`WEBP`。

## 正文插图功能

- 支持直接在正文编辑框里粘贴截图或剪贴板图片，系统会自动把图片放到当前光标位置。
- 上传插图后，可以直接给每张图片选择“第几章、第几段后”。
- 主流程不需要再手动往正文里插入图片标记。
- 导出时会按照你选择的位置，把图片插入到对应章节里。
- 每张图都会显示“前文 / 插图 / 后文”的落点预览，页面下方还有整本书的插图总览。
- 旧版 `[[image:image-1]]` 标记仍然兼容，但现在更推荐直接用界面里的可视化定位。

## 当前限制

- 目录仍为单层章节结构。
- 正文插图目前是按“章首 / 第 N 段后”插入，不支持和普通文字在同一段内混排。
- 图片资源会被直接打包进 EPUB，文件过大时导出体积也会变大。

## 技术栈

- Vue 3
- Vite
- JSZip
- file-saver
